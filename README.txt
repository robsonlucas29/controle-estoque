COMO INSTALAR E ABRIR O SISTEMA

1. Extraia a pasta do arquivo ZIP.
2. Abra a pasta no VS Code.
3. No terminal, execute:

   npm install

4. Para abrir o sistema, execute:

   npm start

Se o Windows tentar abrir electron.js pelo Windows Script Host, use:

   .\node_modules\.bin\electron.cmd .

O sistema não usa preço. Ele controla produtos, setor, quantidade, estoque mínimo, entrada, saída, edição e exclusão.
